## 1. 尺子（SERP 当量宽度）

```
width(s) = Σ 2 (unicodedata.east_asian_width(c) in 'WF') else 1
```

- `title[loc]` ≤ **60**；`metaDescription[loc]` ≤ **155**。
- 实测入口：`python3 scripts/check-n4-length.py --slug <slug>`（带 `--top` / `--json` / `--strict`）。
- **留余量**：改完目标值 ≤ 58 / ≤ 152（至少留 1–2 宽），因为计量单位是当量宽度不是字符数，`M6–M48`、`DIN 931/933`、全角冒号都会吃掉宽度。种子篇 zinc 第一版写 156 差 1 就不过，**必须跑尺子确认到 0，不能肉眼估**。
- 东亚宽字符 2 → zh/ja 的 description 实际只有约 77 个汉字/假名；zh/ja 的 title 约 30 个字。hi/ar/ru/es/fr/de/pt 一字一宽。

## 2. 只动两个字段

- 只允许改 `title[loc]` 与 `metaDescription[loc]`。
- **禁止**动 `description`（顶层，正文摘要）、`sections`、`faq`/`faqItems`、`heading`、`keywords`、`cta`、`imageAlt` 以及任何其它键。
- **禁止**增删语种键：改前 10 个语种，改后必须还是 10 个（en/zh/es/ar/fr/pt/ru/ja/de/hi）。
- 用 Python 改：`json.load` → 赋值 → `json.dumps(ensure_ascii=False, indent=2)`，并保持原文件末尾换行（原文件有 `\n` 就补 `\n`）。这样 diff 只有改动行，不许整文件重排。

## 3. 重写规则（按语种逐条重写，禁止机器截断）

### 3.1 title（≤60）
- 结构固定：**核心词（产品/主题）+ 意图（尺寸表/选购/对比/案例）+ 可选限定（地区/标准）**。
- 保留必须保留的实体：型号（`M6–M48`、`M5.5x50`）、HS 编码（`HS 7318`）、标准号（`ISO 4014`、`DIN 931/933`、`ISO 898-1`）、品牌/专名（`TradeGo`、`EPDM`、`SADC`）。
- **不得**出现英文标题前缀（`Hex Bolt Dimensions Chart:` 这类串进），也不得保留结尾 `…`/`...`。
- 各语种标题语义一致（同一篇讲同一件事），但用本语种自然表达，不做逐词直译。

### 3.2 metaDescription（≤155）
- 一句话价值 + 一个可核对的技术锚点（尺寸区间/标准号/涂层/等级）+ 一句轻 CTA（`询价`/`核实规格`/`get a matched quote`）。
- 判定口径：**不写价格数字**（只写"按规格与批量报价"这类结构表述）；**不写 `ISO 9001 certified`**（只写"按 ISO 898-1 / SABS 1195 / DIN 生产"或"证书按订单提供"）；地域只写 `China`。
- 不得与 title 逐字重复，不得以 en 标题片段起头，不得残留半截词。

### 3.3 半词截断红线（本轮上一轮翻车的根因）
改完必须目检 diff，凡出现以下形态即判不合格并重写整句：
- `HS 7318. 15`（小数点被当句末）
- `Guí` / `fü` / `spécifications, applications…`（前缀剥离残留）
- 任何以单个字母/半个音节结尾、或句尾带 `…` 的字段

**唯一合法做法**：把该语种的整句按语义重写一遍，不保留被截断的残句。
